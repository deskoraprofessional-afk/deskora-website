# Deskora - Curated Desk Essentials & Workspace Accessories 🇮🇳

> **"Curated Desk Essentials for Focused Minds"**  
> Premium e-commerce platform engineered for Indian college students, MBA candidates, remote professionals, and content creators.

---

## 🌟 Brand Overview

**Deskora** is an online retail brand focused on desk essentials and workspace accessories across India. Deskora helps students and working professionals transform cluttered workspaces into ergonomic, functional, and aesthetically pleasing environments.

### Target Audience
- **College & University Students** (Engineering, Design, Commerce, Medicine)
- **MBA Candidates & B-School Scholars** (Case study marathons, financial modeling)
- **Young Professionals & Tech Workers** (Bangalore, Hyderabad, Pune, Gurugram hubs)
- **Remote Workers & Hybrid Employees** (Ergonomics, eye strain reduction, clutter-free desks)
- **Freelancers & Content Creators** (Aesthetic camera-ready workspace setups)

### 1. 🛍️ Conversion-Driven E-Commerce Experience
- **Hero Showcase with Interactive Hotspots**: Clickable hotspot pins on real workspace setups allowing direct product inspection and quick purchase.
- **Curated Workspace Setup Kits (Hero Bundles)**: 
  - *The Student Hustle Setup Kit* (Save 36%)

### 2. 🛒 High-Converting Slide-Over Cart & Drawer

## 🚀 How to Run the Website

### Option 1: Double-Click or Open Directly
You can open `index.html` directly in any web browser (Chrome, Edge, Opera, Firefox, Safari). Zero dependencies or build steps required!

### Option 2: 1-Click Local Server (Recommended)
Run the included PowerShell script to launch a local server with auto-refresh:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then visit **`http://localhost:8080`** in your browser.
